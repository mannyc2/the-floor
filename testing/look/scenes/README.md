# Reference scenes

These briefs hold frame paths, image hashes, dimensions and the rendering inputs available for each scene. The first nine image references retain pending camera, clock, placement and expectation fields until their executable scenes exist. The material and proportion briefs retain their capture settings and numerical values.

The owner’s picks, exclusions and reasons live in [the decision log](../../../docs/decisions.md#the-look) and [the Atlas](../../../docs/atlas.md). A preserved frame does not approve every visible material, asset, count or camera setting. Reference PNGs remain unchanged; a new owner pick is required before replacing them.
