# Chain construction boundary

This is unsigned construction, not a launch workflow: simulation, policy approval, signing, broadcast, vesting and pool quotation remain later work.

`@floor/chains/solana` provides `MeteoraLaunch` and its Layer. The caller supplies every identity, amount-bearing config, token metadata, recent blockhash, expiry height and RPC endpoint. Effect HttpClient reads the quote mint owner and preserves the returned slot; Kit owns address validation, PDAs, Codama codecs and serialization. The bounded path supports the tested legacy SPL base and quote token programs and fails on other owners. It orders decoded mint bytes before PDA derivation, so neither input order is a hidden precondition. `ConfigParametersArgs` is an explicit binary-program parameter input, not a substitute for the future venue configuration builder.

`@floor/chains/evm` provides `DopplerLaunch` and its Layer for the tested Base multicurve path, default governance and Uniswap V2 migration. Addresses, amounts, pool curves, metadata and salt are inputs. The only Doppler import is `/evm`; its client has no wallet and a transport that rejects every RPC request. Construction returns bytes and the intended sender/destination. New chains, migrations or governance choices require their own construction evidence.

`@floor/chains/math` exposes the four promoted native-bigint computations and their tagged errors. Unbounded intermediate arithmetic matches these SDK helpers; the instruction codecs separately enforce wire field widths. Negative amounts are rejected explicitly. These helpers do not implement a complete curve quote.

`@floor/chains/testing` contains only labelled replay inputs and an HTTP test Layer. Production must not import this export. `test/fixtures/` contains the unchanged oracle JSON recorded from the official SDK 1.5.13: 940 SDK 1.5.13 outcomes, ten additional negative-input controls, exact unsigned Solana instruction bytes and account roles, and the EVM calldata digest. Tests compare the new implementation with the recorded expected results; they do not run the old probe or present replay as current chain data. The SDK source checksum is recorded in `math-oracle.json`. Meteora, Anchor, web3.js and BN are absent from this package's runtime and development dependency declarations.

Run leaf tests with `bun run test` from this package. Root formatting, typecheck, lint and bundle fences also apply. Tests cover all 940 oracle cases, negative input errors, the full serialized transaction digest, every IDL account role/order using distinct sentinel identities, variable inputs and mint ordering, RPC failures/unsupported owners, and EVM calldata parity.

Seven reasoned suppression lines cover eight rule occurrences: three executable/test Layer boundaries, the two SDK/browser Promise callbacks, the single Bun test runner bridge, and the equality bridge's two unknown parameters. The equality bridge compares values already decoded by Schemas without coercing away the difference between SDK-branded values and wire records. The 91 compiler diagnostics and all other lint rules remain enabled.

## Reproducible codecs

`idl/source.json` pins Meteora's upstream Anchor IDL commit and SHA-256. `METEORA-LICENSE` preserves its MIT license, including the ported arithmetic. Codama 1.11.0, its Anchor adapter 1.5.6 and JS renderer 2.5.0 generate Kit 8.4.0 codecs. `bun run generate` writes full generic output under ignored `work/chains-promotion/client/`, then the Bun/Effect script verifies the IDL checksum, selects twelve codecs, replaces barrel imports with direct imports, and derives the two unsigned instruction builders from IDL account roles and discriminators. Format generated output with the root formatter and verify the resulting diff before changing any pins. The script fails if the dependency closure changes or selected codecs introduce casts, assertions or `any`.

No Alchemy, Cloudflare binding or application runtime belongs here. The Solana edge supplies Effect's FetchHttpClient internally so its public service does not leak the unstable HTTP interface. Testing Layers replace the documented Fetch reference under that same HTTP/Schema path. The root bundle audit must inspect both production entry points so Doppler's unreachable Kit 6 transitive package cannot enter the signer or Floor graph.
