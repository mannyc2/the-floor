## Dependencies and reproduction

The agent adapter is built from **yielded-dev/agent PR 557 at `0adbcff4c7d4b1a32a3edb1fe1bc92e245a01968`**, using its frozen dependency graph, Effect **4.0.0** and Alchemy **2.0.0-beta.80** with the PR's Bun patch. The [patch compatibility check](alchemy-patch-compatibility/001/record.json) shows that the patch does **not** apply unchanged to beta.81. The adapter remains unpublished, and the owner must decide whether to carry this pinned source and patch or wait for upstream releases before Stage 0. The final native agent/storage [bundle audit](alchemy-native-storage/001/bundle-audit.json) finds no `effect-cf` among reachable static or literal imports, mapped sources or emitted markers; computed imports are outside its scope.

The separate launch probe pins Effect/browser crypto **4.0.3**, Kit **8.4.0**, Codama **1.11.0**, Anchor importer **1.5.6**, JS renderer **2.5.0**, Doppler **1.0.43** and viem **2.44.2**, with the same Alchemy beta.80 patch. Its pinned Meteora IDL comes from commit `a28b7239e71899eb52ff7aacac4dec90441885c4`. The official Meteora SDK is a development oracle only; no web3.js, Anchor, BN or spl-token runtime stack is selected. The reachable bundle audit checks that Doppler's unused Solana Kit 6 dependency does not enter this Worker. These isolated spike graphs do not establish a unified product dependency graph.

The DO test uses a transaction owned by Alchemy; D1 uses an atomic batch through Alchemy’s Effect SQL integration. These are distinct transaction interfaces. Current Alchemy tests do not repeat the historical nested-rollback or unsupported-interactive-transaction controls.

Both probes use compatibility date **2026-08-18** with Alchemy's default flags, and the retained records identify workerd **1.20260918.1** and the actual runtime capabilities. An [exploratory bare-configuration failure](kit-construction/001/record.json) remains a timeout finding with incomplete exact-source provenance; it does not identify a specific unsupported module or prove that every chain dependency requires Node compatibility.

The [probe README](../../../../apps/floor/spikes/platform/README.md), [agent fixture](../../../../apps/floor/spikes/platform/alchemy-agent/README.md) and [launch fixture](../../../../apps/floor/spikes/platform/kit/README.md) describe reproducible commands, source pins, local resource ownership and suppression budgets. `bun install --frozen-lockfile`, `bun run format:check`, `bun run typecheck`, `bun run lint`, `bun run build` and the bounded native restart tests passed. Native agent/storage tests made 33 assertions; the launch/crypto build made 18, with additional assertions inside the Worker probes. Root scripts check authored code with the strict native compiler options, all 91 Effect diagnostics and the retained lint presets. The upstream PR's declarations are generated with its own configuration; that does not weaken the consuming probe's checks. Stage 0 still owns the product packages, architecture fences and full CI.
